# Password Hashing Tool

A command-line tool for hashing passwords.

## Requirements

- Python 3
- `pip`

## Installation

Clone the repository and install its dependencies:

```bash
git clone https://github.com/hmidani-abdelilah/hash.git
cd hash
pip install -r requirement.txt
python3 hash.py
```
